BYTE RAY ADVISORY TEMPLATE
==========================

Read ../../ADVISORY_AUTHORING.md before using this file. The guide is the
source of truth. This .txt extension prevents Pelican from publishing the
examples.

be updated in place when disclosure is permitted.

## Proof of Possession

The commitment above records ByteRay's possession of the private report
without publishing the report or material that assists vulnerability discovery.

Embargo field.

## Executive Summary

Explain the issue and practical consequence in plain language.

## Affected Products and Versions

List exact products, components, configurations, and version boundaries.

## Technical Details

Describe the root cause and vulnerable data or control flow.

## Reachability and Preconditions

State attacker position, authentication, privileges, user interaction,
configuration, and other prerequisites.

## Impact

Describe the confirmed consequence of exploitation.

## Remediation and Mitigation

Link the fix, identify the first fixed version, and explain mitigations.

OPERATIONAL NOTES
-----------------

- Allocate the next ID with:
  uv run python scripts/validate_advisories.py --next-id
- Validate with:
  uv run python scripts/validate_advisories.py
- Build with:
  uv run pelican content --settings publishconf.py
- `Status: draft` prevents publication. It is not a public embargo.
- Never put private details in comments, attachments, filenames, or Git history.
- Never commit or push as part of an authoring prompt unless explicitly asked.
